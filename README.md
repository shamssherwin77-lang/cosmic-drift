# Cosmic Drift

تجربه‌ای سه‌بعدی و آرام برای سفر در کیهان، با React، TypeScript، Three.js و WebGL؛ بدون سرور، حساب کاربری یا API پولی.

## اجرای برنامه در ویندوز

1. نسخهٔ LTS از Node.js (نسخهٔ ۲۲ یا ۲۴) و Git را نصب کنید.
2. PowerShell را باز کنید:

```powershell
git clone https://github.com/shamssherwin77-lang/cosmic-drift.git
cd cosmic-drift
npm ci
npm run dev
```

آدرس نمایش‌داده‌شده در ترمینال را در Chrome، Edge یا Firefox باز کنید. شتاب‌دهی سخت‌افزاری مرورگر و WebGL باید فعال باشند.

```powershell
npm run build
npm run preview
```

فرمان اول TypeScript و خروجی تولیدی را بررسی می‌کند؛ فرمان دوم همان خروجی را برای بازبینی اجرا می‌کند. پوشهٔ `dist` روی هر میزبان فایل استاتیک قابل انتشار است. برای نصب نخست دسترسی به registry.npmjs.org لازم است. رندر و صدا به هیچ سرویس خارجی وابسته نیستند و پس از بارگذاری برنامه به‌صورت محلی کار می‌کنند.

## کنترل‌ها

- **Start journey:** شروع حرکت؛ **Pause / Resume** یا Space: توقف و ادامه.
- **Autopilot:** حرکت آرام خودکار؛ **Manual Flight:** چرخش سفینه با WASD یا جهت‌ها.
- درگ موس روی فضا: نگاه به اطراف. لغزندهٔ Drift speed سرعت سفر را تنظیم می‌کند.
- **Meditation mode:** حرکت آهسته‌تر و محوشدن اطلاعات اضافی.
- **Explore regions:** انتخاب پنج منطقه؛ گزینهٔ خودکار هر ۹۰ ثانیه منطقه را عوض می‌کند. رنگ و نور سحابی‌ها به‌تدریج تغییر می‌کنند.
- آیکن صدا در پایین: فعال‌سازی یا قطع صدا؛ آیکن صدای بالا: تنظیم مستقل موسیقی و موتور. تمام صداها با Web Audio API ساخته می‌شوند و فایل دارای حق نشر ندارند.
- تنظیمات: کیفیت Low / Medium / High، میزان حرکت خودکار دوربین، Reduced motion و نمایش کابین.
- آیکن تمام‌صفحه: ورود یا خروج؛ **H**: پنهان‌کردن رابط؛ **Escape**: نمایش رابط و بستن تنظیمات.

## جزئیات فنی و محدودیت‌ها

تا ۲۴٬۰۰۰ ستاره با BufferGeometry و shader اختصاصی، هفت لایهٔ سحابی رویه‌ای با نویز چندمقیاسی، سیاره، نورپردازی و کابین سه‌بعدی رندر می‌شوند. تعداد ستاره و نسبت پیکسل با کیفیت تغییر می‌کند. جلوهٔ حجمی سحابی تقریبی و لایه‌ای است؛ شبیه‌سازی فیزیکی حجمی یا میلیون‌ها ستارهٔ مجزا نیست. سرعت و فاصله‌ها هنری‌اند و مقیاس نجومی واقعی ندارند. برای سیستم‌های ضعیف Low را انتخاب کنید؛ Reduced motion حرکت خودکار زاویهٔ دوربین را حذف و سرعت عبور را کم می‌کند. صدای محیط از نوسان‌سازهای اصلی و بدون ضرب تند ساخته شده است.

هیچ دشمن، امتیاز، مأموریت یا محدودیت زمانی وجود ندارد. پروژه هیچ داده‌ای از کاربر ذخیره نمی‌کند.
